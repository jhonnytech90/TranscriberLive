# Vocabulario PT-BR do Transcriber Live
# ---------------------------------------------------------------------------
# Tres usos, e a diferenca entre eles importa:
#
#   1) secao [prompt] -> vai para o initial_prompt do whisper, ANTES de
#      transcrever. Inclina o modelo para este dominio. O whisper corta em
#      224 tokens (n_text_ctx/2) e guarda os ULTIMOS, e esses tokens sao
#      recalculados a CADA frase. Por isso e curto. Lista grande aqui nao
#      ajuda: e cortada E faz o modelo inventar palavra que ninguem falou.
#
#   2) secao [acentos] -> DEPOIS de transcrever. So conserta a GRAFIA de uma
#      palavra que saiu com as MESMAS letras: "equalizacao" recebe a cedilha
#      e o til, "Jonatas" recebe o circunflexo. Nunca troca uma palavra por
#      outra. Por isso esta lista pode ser enorme sem risco nenhum.
#
#   3) campo "Termos" da interface -> nomes da banda e das musicas DESTE
#      show. E a unica coisa que recebe correcao por APROXIMACAO (trocar
#      palavra parecida por outra), porque a lista e curta e especifica.
#
#      Aproximacao contra lista generica nao presta, e isso foi medido: com
#      a lista toda habilitada, "nao consigo ouvir o meu ponto" saia como
#      "meu ponte", porque "ponte" esta na lista e fica a uma letra de
#      distancia. Num show, trocar uma palavra certa por outra e pior do
#      que nao corrigir nada.
#
# Linha comecando com # e comentario. Uma entrada por linha.
# Este arquivo fica na pasta de dados do plugin e pode ser editado.
# ---------------------------------------------------------------------------
